# BinGo: E-Waste Collection and Recycling App

BinGo is a multi-role mobile application I developed in **Thunkable in 2024** to help connect e-waste generators, collectors, and recyclers through a single workflow.

The app includes separate interfaces for Customers, Collectors, and Recyclers, along with an awareness section containing an e-waste classification quiz.

## What the app does

- Customer e-waste request submission
- Customer → Collector → Recycler workflow
- Role-based navigation
- User sign-in and sign-up
- Pickup scheduling
- E-waste weight tracking
- Recycler request validation
- Database-backed request storage and retrieval
- Google Maps integration for collector locations
- Randomized waste-classification quiz with answer feedback

## Source-code note

BinGo was originally developed using **Thunkable's visual block programming environment**, rather than a text-based Git repository.

Because the original Thunkable project currently requires a Thunkable account to access, this repository serves as a public archive of the original visual block code, interface, testing evidence, and project documentation.

The screenshots included here were captured from my original BinGo project and show the logic used to build the application.
